# 📦 Warehouse Manager App

Приложение для учёта товаров и остатков на складе.  
Создано на **Flutter** с использованием **Hive** для локального хранения данных.  
Позволяет добавлять, редактировать, удалять товары и управлять их остатками на складах.

---

## 🚀 Описание

**Warehouse Manager** — это мобильное Flutter-приложение для управления товарами и складскими остатками.  
Оно сохраняет данные локально, поэтому работает офлайн и не теряет данные при перезапуске.

---

## 🧩 Основной функционал

### ✅ Управление товарами
- Добавление нового товара (с валидацией GTIN — 13 цифр);
- Редактирование и удаление товара;
- Просмотр списка товаров (название, цена, дата);
- Сортировка по дате создания и названию;
- *(Бонус)* Загрузка изображения;
- *(Бонус)* Поиск товара по GTIN;
- *(Бонус)* Подтверждение удаления через модальное окно.

### ✅ Управление остатками
- Добавление записей (склад, GTIN, количество);
- Автоматическое увеличение количества, если товар уже есть;
- Просмотр всех остатков;
- *(Бонус)* Уменьшение количества с проверкой;
- *(Бонус)* Фильтрация по складам;
- *(Бонус)* Подсчёт общей суммы по всем складам.

### ✅ Сохранение состояния
- Все данные сохраняются между перезапусками;
- Используется Hive для локального хранилища;
- *(Бонус)* Архитектура `repo → service → usecase` для расширяемости.

### ✅ Интерфейс
- Современный и минималистичный UI;
- Списки товаров и складов с карточками и кнопками;
- *(Бонус)* Поддержка тёмной темы;
- *(Бонус)* Адаптивный дизайн для планшетов.

---

## 🛠️ Технологии

- **Flutter** — кроссплатформенная разработка  
- **Dart** — язык программирования  
- **Hive** — локальная база данных  
- **BLoC / Cubit** — управление состоянием  
- **Provider / GetIt** — зависимость и DI (опционально)  
- **Path Provider, Image Picker** — для работы с файлами и изображениями
